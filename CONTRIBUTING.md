# Правила контрибьютинга

Спасибо за интерес к нашему проекту! Мы приветствуем все улучшения и новые идеи. Пожалуйста, следуйте этим рекомендациям при внесении изменений.

## Как начать

1. Форкните репозиторий
2. Клонируйте ваш форк: `git clone https://github.com/YOUR_USERNAME/irregular-verbs-trainer.git`
3. Создайте новую ветку для вашей функции: `git checkout -b feature/your-feature-name`
4. Вносите изменения
5. Отправьте pull request

## Требования к коду

### JavaScript (48.1%)
- Используйте четкие и понятные имена переменных
- Добавляйте комментарии к сложной логике
- Избегайте глобальных переменных где это возможно
- Используйте `const` и `let` вместо `var`

### HTML (36.9%)
- Используйте семантический HTML5
- Обеспечьте доступность (добавляйте alt текст для изображений)
- Правильно структурируйте документ

### CSS (15%)
- Используйте классы вместо inline стилей
- Соблюдайте консистентное форматирование
- Используйте переменные CSS где возможно
- Мобильный first подход

## Типы контрибьюций

### Новые функции
- Описывайте назначение функции в PR
- Тестируйте на разных браузерах
- Убедитесь, что функция работает корректно

### Исправления ошибок
- Объясняйте найденную ошибку
- Описывайте способ воспроизведения
- Предлагайте решение

### Улучшения словаря
- Проверяйте правильность глаголов
- Убедитесь в корректности форм
- Добавляйте примеры если возможно

### Документация
- Опишите изменения понятным языком
- Добавляйте примеры где необходимо

## Процесс pull request

1. Убедитесь, что ваш код соответствует требованиям выше
2. Создайте pull request с понятным описанием
3. Ответьте на комментарии рецензентов
4. Дождитесь утверждения
5. Ваш PR будет слит в main

## Поведение в сообществе

- Будьте вежливы и уважительны
- Помогайте другим контрибьюторам
- Принимайте конструктивную критику
- Сосредоточьтесь на идеях, а не на людях

## Вопросы?

Если у вас есть вопросы, создайте issue или свяжитесь с мейнтейнерами.
