О сайте

Тренажёр неправильных английских глаголов. Помогает запоминать формы V1, V2 и V3 через карточки, тренировки и работу над ошибками.

Как пользоваться сайтом

  • 1
    Словарь — просматривайте все глаголы, ищите по названию, фильтруйте по группам. Нажмите на строку, чтобы увидеть подробную статистику по глаголу.
  • 2
    Карточки — переворачивайте 3D-карточки, чтобы увидеть все формы глагола. Листайте вперёд/назад.
  • 3
    Буквы — вставьте пропущенные буквы в форму глагола. Тренирует зрительную память правописания.
  • 4
    Формы — основной тренажёр. Введите V2 и V3 по инфинитиву. Доступны режимы: V1→V2/V3, Перевод→V1, V2/V3→V1, Предложения, Аудио, Сопоставить.
  • 5
    Ошибки — повторите глаголы, в которых были допущены ошибки. Формы, Буквы или Тест.
  • 6
    Спринт — отвечайте на вопросы на время. 60 секунд, +1 сек за правильный ответ.
  • 7
    Предлоги — вставьте правильный предлог к глаголу (listen to, depend on, wait for и т.д.).

Группы глаголов

Неправильные глаголы делятся на 4 группы по тому, как меняются их формы:

AAA — все три формы одинаковые
V1 = V2 = V3
cut → cut → cut = резать
Примеры: cut, put, let, set, shut, burst, cost, hit, hurt
ABB — формы прошлого времени совпадают
V2 = V3 (Past Simple = Past Participle)
bring → brought → brought = приносить
Самая большая группа. Примеры: buy, catch, feel, find, get, have, hear, keep, lead, leave, lose, make, mean, meet, pay, say, sell, send, sit, sleep, spend, stand, teach, tell, think, understand, win
ABA — инфинитив и причастие совпадают
V1 = V3 (Infinitive = Past Participle)
come → came → come = приходить
Примеры: become, come, run
ABC — все три формы разные
V1 ≠ V2 ≠ V3
go → went → gone = идти
Примеры: be, begin, break, choose, do, drink, drive, eat, fall, fly, forget, give, know, ride, rise, see, show, speak, swim, take, tear, throw, wake, wear, write

Используйте фильтр по группам в словаре и тренажёрах, чтобы изучать глаголы по этим шаблонам.
