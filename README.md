# Irregular Verbs Trainer

Тренажёр неправильных английских глаголов. Vanilla JS, один HTML-файл, без фреймворков.

## Возможности

- **Словарь** — полный список глаголов с формами V1/V2/V3, избранное, поиск
- **Буквы** — вставь пропущенные буквы в форму глагола
- **Формы** — введи V2 и V3 по памяти
- **Ошибки** — работа над ошибками (формы / буквы / викторина)
- **Статистика** — точность, количество сессий, график по дням, топ ошибок
- **Тёмная тема** — автоматически по системным настройкам, ручное переключение
- **Звуковые эффекты** — короткий сигнал при правильном/неправильном ответе
- **Интервальные повторения** — чаще показывать глаголы, в которых были ошибки
- **Озвучка** — произношение глаголов через Web Speech API
- **Достижения** — 6 ачивок за прогресс
- **Свои глаголы** — добавление собственных глаголов в словарь
- **i18n** — русский и английский интерфейс
- **localStorage** — все настройки, прогресс, история сохраняются

## Стек

- Vanilla JS (ES6+)
- CSS Custom Properties
- Web Speech API (TTS)
- Web Audio API (звуки)
- Font Awesome 6
- localStorage
- GitHub Pages

## Разработка

Локально открыть `index.html` в браузере — и всё. Никаких сборщиков.
